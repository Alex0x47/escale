# Changelog

All notable changes to Escale Community are documented here.

## Unreleased

- Added contextual callouts and feature entry points for official-distribution
  workflows. Community controls open an informational Pro sheet without
  restoring commercial implementations, entitlements, or operation hooks.
- Clarified during App Store Connect setup that fetching iOS apps can take a few
  minutes for larger accounts.
- Made the built-in demo an interactive Escale Pro preview with safe, local
  simulations for bulk localization, templates, price application, AI replies,
  and Android draft creation.
- Added a prominent Leave demo workspace button above Feedback & requests.

## 1.0.1 — 2026-07-31

- Defined a strict Community-only source boundary and removed dormant
  commercial workflow implementations, locks, entitlements, and paywall UI.
- Added Apache-2.0 licence text to locally built Community app bundles.
- Added CI, security reporting, contribution guidance, and release hygiene.
- Changed the optional pre-commit hook to validate versions without modifying
  them.

## 1.0.0 — 2026-07-30

- First public Apple silicon release.
- Added signed Sparkle updates, Developer ID signing, notarization, and a stable
  DMG download.
