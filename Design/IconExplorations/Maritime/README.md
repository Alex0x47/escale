# Escale maritime icon directions

This round uses concrete maritime objects rather than abstract workflow marks.

1. **Mooring cleat with line** — a vessel ties up temporarily, then continues.
   This is the closest literal expression of an *escale*.
2. **Lighthouse** — a port of call, a safe point, and a familiar coastal symbol.
3. **Anchor** — the clearest universal symbol for stopping at sea, though less
   distinctive as a software brand.
4. **Mooring buoy** — a temporary berth or waypoint between journeys.
5. **Flag buoy** — the selected direction: a small floating white buoy with a
   large coral flag and subtle water ripples. The flag is the primary brand
   gesture; the buoy has no contrasting stripe.

The current violet is retained for brand continuity. Coral identifies the
temporary stop or active maritime element. These are explorations only; no
production icon has been replaced.
