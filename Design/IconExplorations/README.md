# Escale icon explorations

Four non-destructive vector directions for replacing the old helm:

1. **Route E** — a transit-map monogram; the coral node is the layover.
2. **Convergence** — two stores meet at one deliberate checkpoint, then ship.
3. **Stepping stones** — updates progress through calm, discrete stages.
4. **Terminal window** — the most atmospheric interpretation of a layover.

All four retain the current violet (`#7064E8`) to preserve recognition. Coral
(`#F27D66`) is used sparingly as the active stop/checkpoint.

These are concept vectors, not final production masters. Before adoption, the
chosen mark should be optically tuned at 16, 32, 64, 128, 512, and 1024 px.
